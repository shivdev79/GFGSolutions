<h2><a href="https://www.geeksforgeeks.org/problems/intersection-of-two-arrays2404/1">Intersection of Arrays with Distinct</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given two unsorted integer arrays a[] and b[], each consisting of distinct elements, find the intersection (common elements) of the two arrays.</span></p><ul><li><span style="font-size: 14pt;">Returned must contain each common element exactly once.</span></li><li><span style="font-size: 14pt;">The order of elements in the returned array should be same as a[].</span></li></ul><p><strong><span style="font-size: 18px;">Examples:</span></strong></p><pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [89, 24, 75, 11, 23], b[] = [89, 2, 4]<strong>
Output:</strong> [89]<strong>
Explanation: </strong>89 is the only element in the intersection of the two arrays.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [1, 2, 4, 3, 5, 6], b[] = [3, 4, 5, 6, 7]
<strong>Output:</strong> [4, 3, 5, 6]
<strong>Explanation: </strong>The common elements are 3, 4, 5, and 6. In a[], they appear in the order 4, 3, 5, 6 (since 4 comes before 3 in a[]), so the result follows that order.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [20, 10, 30, 50, 40], b[] = [15, 25, 30, 20, 35]<strong>
Output: </strong>[20, 30]<strong>
